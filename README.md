A lightweight and reusable Azure infrastructure template built using Terraform.  
This project is mainly used for quick testing, infrastructure validation, CI/CD pipeline automation, and experimenting with new Azure DevOps and GitHub Actions workflow parameters.

---

# 🚀 Purpose of this Repository

This repository contains a simple and basic Terraform configuration used for:

- Infrastructure testing
- Azure resource provisioning
- GitHub Actions pipeline validation
- Azure DevOps pipeline testing
- Automation practice
- Fast deployment of temporary environments

The goal is to provision Azure resources quickly without unnecessary complexity.

---

# 🏗️ Resources Included

| Resource | Purpose |
|----------|----------|
| Resource Group | Resource container |
| Virtual Network | Private networking |
| Subnet | VM subnet |
| Public IP | External connectivity |
| Network Interface | VM networking |
| Linux Virtual Machine | Ubuntu test server |
